# Garment Style and Colour Detection frontend

This directory preserves the supplied ThreadScan React application and its Tailwind v4 UI.

- Card: **Garment Style and Colour Detection**
- Root UI: `App.tsx`
- Desktop adapter: `StyleColourWorkspace.tsx`
- Backend: `../../backend/garment-style-colour-backend/`
- Model: `../../models/garment-style-colour/best.pt`

Its styles are scoped under `.threadscan-module` and compiled by the shared Webpack/PostCSS pipeline so the standalone visual layout does not leak into the selection page.
