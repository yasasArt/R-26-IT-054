# Garment Size Detection frontend

This directory preserves the supplied size-detection React application.

- Card: **Garment Size Detection**
- Root UI: `SizeApp.tsx`
- Desktop adapter: `SizeWorkspace.tsx`
- Backend: `../../backend/garment-size-backend/`
- Model: `../../models/garment-size/best_model.pt`

Its original component styles and live-scanner styles are contained under `.garment-size-module` to prevent global CSS collisions with the platform or other research components.
